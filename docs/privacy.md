# Privacy Policy

*Last updated: 2026-07-29*

## Summary

chromium-safestorage is a local Rust library and CLI. It does not collect, transmit, or store any personal data on remote servers.

## Data Access

chromium-safestorage reads only the file bytes and inputs you pass to it — keychains, `Local State` files, cookie blobs. All processing — key recovery and decryption — happens in memory on your local machine. Nothing is uploaded anywhere.

## Telemetry

chromium-safestorage has **no telemetry**. It makes no network requests of any kind.

## Open Source

chromium-safestorage is open source (Apache-2.0). You can audit every line of code at [github.com/SecurityRonin/chromium-safestorage](https://github.com/SecurityRonin/chromium-safestorage).
